# Obrony-Archiwum

Archiwum dokumentów publicznych obron doktorskich w Instytucie Matematycznym UWr, przeniesionych ze starej strony
(math.uni.wroc.pl, stan z października 2026): zawiadomienia, rozprawy (jeśli były na stronie), streszczenia i recenzje.
Te pliki się już nie zmieniają.

Repozytorium nie jest podłączone do Pages CMS ani do budowy strony (Web-Core). GitHub Pages serwuje pliki bezpośrednio
z gałęzi `main` pod adresem `https://im-uwr.github.io/Obrony-Archiwum/<folder>/<plik>.pdf`.

- Jeden folder na obronę: `<data>-<imię-nazwisko>/`. Nazwa folderu = nazwa wpisu obrony w Web-Aktualnosci
  (`src/content/obrony/<data>-<imię-nazwisko>.md`); nazwy plików jak na starej stronie.
- Nowe obrony redaktorzy dodają w Pages CMS (Web-Aktualnosci → Obrony doktorskie), a ich pliki trafiają do
  Web-Aktualnosci (`public/pliki/obrony/`), nie tutaj.

**Nie zmieniaj nazw ani ścieżek plików** — linkują do nich wpisy obron na stronie.
